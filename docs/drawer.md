# 서랍장 (실 · 바늘)

하단 4번째 탭. 사용자가 가진 실과 바늘을 정리하고, 프로젝트에 연결해 용도·사용량을 기록한다.
`src/constants/feature.constant.ts`의 `DRAWER_TAB_ENABLED`로 켜고 끈다. prod 배포 전 스토어 빌드에서는 **false**로 둘 것 (프로젝트 상세의 실/바늘 연결 UI·RPC 호출도 함께 꺼짐).

## 기능 요약

### 실

- 추가 방식: **Ravelry 에서 가져오기** / **직접 입력**
  - Ravelry: 진입 시 인기순(프로젝트 많은 순) 목록 → 검색 → 선택하면 상세 조회 후 폼 자동 채움
  - 자동 채움: 이름, 브랜드, 합수(이름의 "N ply" 우선), 성분, 게이지, 권장 바늘, 볼당 중량·길이(yds → m로 변환), 사진
- 입력 항목: 이름(필수), 브랜드, 색상, LOT(염색 번호), 합수, 성분, 게이지, 권장 바늘, 볼당 중량·길이, 구매량(볼), 구매처, 구매일, 가격, 메모, 사진
- 1행 = 색상 1개 + LOT 1개. 같은 LOT를 추가 구매하면 구매량만 수정, LOT가 다르면 새 실로 추가
- **남은 양 자동 계산**: 구매량(볼 수 × 볼당 중량) − 프로젝트별 사용량 합계. 음수면 구매량 업데이트 안내

### 바늘 (직접 입력만)

- 종류: 대바늘 / 코바늘
- 모양: 줄바늘 · 조립식 · 장갑바늘 · 막대바늘 / 코바늘 · 아후강
- 구성: 단품 / 세트 — 세트는 호수·케이블 길이를 여러 개 선택
- 호수는 **mm로만 저장·표시**. 폼에서 호수(국내/일본식)·US → mm 변환표를 참고용 팁으로 제공
- 케이블 길이: 줄바늘 · 조립식 · 아후강만
- 이름은 선택. 비우면 자동 생성 — 단품 `브랜드 4mm 줄바늘 80cm`, 세트 `브랜드 조립식 세트 3–8mm`

### 프로젝트 연결

- 실·바늘 ↔ 프로젝트 양방향 연결 (서랍장 폼에서 / 프로젝트 상세에서)
- 프로젝트 상세: **서랍에서 고르기** + 서랍에 새로 추가(저장 시 해당 프로젝트에 자동 연결 후 복귀)
- 기존 프로젝트의 직접 입력 텍스트(`yarn_info`, `needle_info`)는 그대로 유지 — 게시물 화면에서도 사용
- 프로젝트별 실 **용도**(메인/배색/합사 + 직접 만든 태그)와 **사용량**(g/볼 입력, g로 저장)
  - 실 자체가 아니라 실-프로젝트 연결에 저장 (같은 실도 프로젝트마다 역할·양이 다름)
  - 직접 만든 태그는 그 프로젝트의 그 실에만 붙음

### 프로젝트 게이지
- 프로젝트 상세 > 뜨개 정보에 **게이지** 줄 추가. 실의 (권장) 게이지와 별개로, 내가 실제로 뜬 값
- 한 프로젝트에 여러 개 가능 (예: 몸판 메리야스 / 소매 무늬). 기준은 10cm 고정
- 입력 칸: 코수(필수) · 단수 · 바늘(mm) · 무늬 → 표시 `22코 × 30단 / 10cm · 4mm · 메리야스`
- 공개 프로젝트면 다른 사용자도 볼 수 있음 (뜨개 로그와 같은 공개/차단 규칙)

### 공개 범위

- 공개 프로젝트면 다른 사용자도 연결된 실·바늘 정보(사진, LOT 포함)와 프로젝트별 용도·사용량을 볼 수 있음
- 구매처·구매일·가격·구매량, 메모는 작성자만 서랍장 상세(실·바늘 정보 화면)에서 볼 수 있음
- 폼의 구매 정보 섹션에 🔒 "나만 볼 수 있어요" 표시
- 비공개 프로젝트, 차단 관계에서는 노출 안 됨 (기존 프로젝트 공개 규칙과 동일)
- 다른 사람 프로젝트 상세: 값이 없는 실·바늘·도안 항목은 숨김. 전부 비면 뜨개 정보 섹션 숨김, 로그가 없으면 뜨개 로그 섹션 숨김

## 구현 메모

### DB (`supabase/migrations`)

| 파일                                              | 내용                                                                            |
| ------------------------------------------------- | ------------------------------------------------------------------------------- |
| `20261112000000_add_user_yarns.sql`               | `user_yarns`, `user_yarn_projects`, `yarn-images` 버킷                          |
| `20261112000001_add_user_needles.sql`             | `user_needles`, `user_needle_projects`, `needle-images` 버킷                    |
| `20261112000002_add_project_drawer_items_rpc.sql` | `user_yarn_projects.used_grams`·`purpose_tags` + `get_project_drawer_items` RPC |
| `20261112000003_add_project_gauges.sql` | `project_gauges` (프로젝트 게이지) |

- 실·바늘 테이블 RLS는 **본인 전용**. 다른 사용자에게는 `get_project_drawer_items(project_id)` RPC(SECURITY DEFINER)로만 공개
  - RLS는 행 단위라 열어주면 메모·구매 정보 컬럼까지 노출되기 때문
  - RPC는 메모를 항상 제외하고, 작성자가 아니면 구매 정보·구매량도 제외
- 사진은 `{bucket}/{user_id}/파일` 경로. 교체·삭제 시 이전 파일도 Storage에서 정리

### Edge Function

- `ravelry-yarn-search`: `GET /yarns/search.json` 프록시 (`query`, `page`, `page_size`, `sort`). 검색어 없이 `sort=projects`면 인기순
- `ravelry-yarn-detail`: `GET /yarns/{id}.json` (패턴 쪽과 공유)
- 시크릿 `RAVELRY_USERNAME` / `RAVELRY_PASSWORD`

### 클라이언트

- 화면: `src/screens/Drawer/*`, 프로젝트 상세 연결 UI는 `src/screens/ProjectDetail/ProjectDrawerLinks.tsx`
- 로직: `src/lib/userYarns.ts`, `src/lib/userNeedles.ts`, `src/lib/ravelryYarn.ts`, `src/lib/projectDrawerLinks.ts`
- 서랍장 화면(실/바늘 폼·상세, Ravelry 검색)은 `drawerItemScreens`로 묶어 서랍장·프로젝트·홈·게시물 스택에 공통 등록 — 프로젝트 상세가 여러 스택에 있어서, 탭 이동 없이 같은 스택에서 열기 위함
